# Отчёт по оплате работ

Открой эту папку в терминале и запусти скрипт на Python 3.9 или новее. Дополнительные пакеты не нужны.

```sh
python3 report.py 10.11.2026
```

Отчёт выводится в консоль. Дата включается целиком. Поддерживается и формат ISO, например `2026-11-10`.

По умолчанию программа читает `contracts.csv`, `works.csv` и `payments.csv` из папки `data/` рядом со скриптом. Чтобы взять файлы из другой папки, передай её путь.

```sh
python3 report.py 2026-11-10 --data-dir /path/to/data
```

Из этой же папки можно запустить тесты.

```sh
python3 -B -m unittest -v
```

Правила расчёта описаны в [DECISIONS.md](DECISIONS.md). Краткая инструкция для бухгалтера лежит в [TO_ACCOUNTANT.md](TO_ACCOUNTANT.md).
